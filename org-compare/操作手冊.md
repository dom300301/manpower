# 組織法規與編制表查詢系統　操作手冊

版本：2026-10-31　　適用對象：組編人力處同仁（不需程式背景）

---

## 一、這套系統是什麼

- 一個網頁檔 `index.html`，內含行政院所屬 585 個機關的組織法規條文、處務規程、編制表明細，以及每個機關的結構指標（員額、副組長設置、簡任非主管比例等）。
- 用途：查某機關的組織與編制；挑同層級、同性質的機關做比對，支援機關增設、調整層級或員額時的分析。
- 資料來源：全國法規資料庫（開放資料與編制表 PDF），2026 年 10 月版；另有少數機關取自行政院公報。
- 不連網也能用；上傳到網站主機就是線上版。

## 三、怎麼用查詢網頁

### 1. 機關查詢
1. 雙擊 `index.html`（用 Edge 或 Chrome 開啟；第一次開啟約需 2 秒載入）。
2. 在搜尋框輸入機關名稱或業務關鍵字，用空格分隔表示「同時符合」，例如「海洋 保育」。
3. 可用「層級」「類型」「部會」按鈕縮小範圍。
4. 點左側機關，右側會顯示：
   - 基本資料與法規資料庫連結（組織法規、編制表 PDF）。
   - 指標卡片：員額合計、首長職等、副首長（只算本機關首長的副手，例如署的副署長、部的副部長與次長；內部單位的副處長不計）、業務單位與幕僚單位數、科數（均取自處務規程「設下列組、室」條文）、組長／副組長、科長、專門委員、簡任員額與比例、簡任非主管、官等結構、主管比、幕僚比、暫列與得列。
   - 掌理事項（組織法第 2 條）、編制表明細、組織法規與處務規程全文（可展開）。
5. 按「以此機關進行同級比對」直接帶到比對頁。

### 2. 同級比對（例：海洋保育署擬提高層級或擴增員額）
1. 在「目標機關」輸入「海洋保育署」並選取。
2. 系統預設比較群組為「同層級、同類型」（三級「署」，46 個）。可再：
   - 勾選其他層級或類型（例如同時看三級「局」）。
   - 選部會。
   - 設員額範圍，或按「目標 ±50%」只看規模相近的機關。
   - 輸入業務關鍵字（比對組織法掌理事項），例如「保育」「污染」「野生動物」。
   - 「排除」預設排除驗算狀態非相符的機關；可再排除醫療、警消海巡、軍事、矯正、駐外、學校、國稅局分局。
3. 結果表：黃底為目標機關，「中位數」「平均」列為群組統計；點欄名排序；上方可勾選要顯示的指標。
4. 「匯出 CSV」可直接用 Excel 開啟；「複製表格」可貼到 Word 或 Excel。

### 3. 指標說明與資料狀態
列出每個指標的定義、資料版本，以及驗算狀態非「相符」的機關清單（這些機關的員額數字使用前請對照 PDF）。

## 四、資料更新（組織法或編制表修正、新機關成立時）

有兩種做法，擇一即可。

### 做法 A：請 Claude 做（最簡單）
在 Claude Code 開啟程式庫 `dom300301/manpower`（環境請選已開放法規資料庫網域者），輸入：

> 請執行組織法編制表更新：檢查更新、重新解析有異動的機關、補入新機關、重新建檔，並把結果推送到分支。

Claude 會依本手冊第五節的流程執行，並回報有哪些法規異動、哪些機關需要人工確認。

### 做法 B：自己在 Mac 上雙擊執行
前置（一次）：安裝 Python 3（App Store 或 python.org），把 GitHub 的 `org-compare` 資料夾下載到電腦，雙擊 `0_首次安裝.command`。

| 步驟 | 雙擊 | 做什麼 | 產出 |
|---|---|---|---|
| 1 | `1_檢查更新.command` | 下載法規資料庫開放資料，比對總表 | `更新偵測報告.md`（異動、廢止、附件變更、未收錄法規）、`pending_updates.json` |
| 2 | `2_更新資料.command` | 重新下載解析有異動的機關，並補入 `new_agencies.json` 內的新機關 | `data/組織法編制表_總表_日期.xlsx` |
| 3 | 人工 | 打開新總表的「檢核_待人工確認」工作表，需補登的列寫進 `manual_fixes.json` | |
| 4 | `3_建檔.command` | 重新產生查詢網頁並開啟 | `output/index.html` |
| 5 | 分享 | 把 `index.html` 與新總表上傳到雲端硬碟，或推回 GitHub | |

### 新機關怎麼加
1. 在全國法規資料庫找到該機關的組織法規、處務規程、編制表三個頁面，記下網址中的 `pcode=` 後面 8 碼（例如 `D0090032`）。
2. 在人事總處機關代碼表查機關代碼與層級（https://www.dgpa.gov.tw/open/code/orglist.csv ）。
3. 在 `new_agencies.json` 照既有格式加一筆（機關、機關代碼、層級、隸屬、部會、組織法規、處務規程、編制表）。
4. 執行上面步驟 2 至 4。
`1_檢查更新.command` 的報告第四節會自動列出「開放資料有、總表沒有」的組織類法規，是發現新機關最快的方法。

### 程式讀不好的編制表怎麼辦
約 5% 的 PDF 版面特殊（內嵌字型、掃描檔、多職稱共用員額），程式會在「檢核_待人工確認」列出。處理方式：打開 PDF 對照，把正確的列寫進 `manual_fixes.json`（動作：新增列／刪除列／改合計），建檔時會自動套用，總表 Excel 本身不必改。

## 五、更新流程背後的程式（給需要了解細節的人）

| 程式 | 功能 |
|---|---|
| `check_updates.py` | 下載 ChLaw.json／ChOrder.json，比對總表條文日期與內容、編制表附件 FileId；輸出報告與 `pending_updates.json` |
| `add_agencies.py` | 依設定檔下載條文與 PDF、解析編制表、寫入總表；`--replace` 為更新既有機關 |
| `reparse_pdfs.py` | 編制表 PDF 解析器（`add_agencies.py` 共用），也可獨立用來重新驗證 |
| `build_dataset.py` | 總表 → JSON，計算指標，套用 `manual_fixes.json` |
| `build_org_search.py` | JSON 嵌入 `org_template.html` → `output/index.html` |
| `verify_tables_online.py` | 逐頁檢查法規資料庫編制表頁面（驗證用） |

## 六、線上版（選用）
1. GitHub 專案 → Settings → Pages → Source 選「GitHub Actions」（一次）。
2. 把分支合併到 `main` 後，每次 `org-compare/output/index.html` 更新都會自動發布，網址為 `https://dom300301.github.io/manpower/`。
3. 若改用貴處既有的 Firebase Hosting，把 `index.html` 放進 `public/` 資料夾後執行 `firebase deploy` 即可。
資料全為公開法規，無保密需求；若日後加入預算員額、現有員額等內部資料，請改用質詢系統的密碼加密方式發布。

## 七、常見問題
- **網頁打開一直顯示「資料載入中」**：瀏覽器太舊。請用 Edge／Chrome 80 以上；或請建檔者以 `--no-compress` 重新建檔（檔案會變成約 15 MB）。
- **某機關員額和 PDF 不一樣**：先看「指標說明與資料狀態」頁是否列為待確認；是的話依第四節補登。
- **想加新的指標**：指標在 `build_dataset.py` 的 `profile` 函式計算，比對表欄位在 `org_template.html` 的 `COLS` 清單；請 Claude 修改最快。
- **總表裡的「括號員額」是什麼**：編制表上以括號標示的兼任員額，不計入合計；明細「兼任」欄另記。
- **為什麼有些機關沒有編制表**：法規資料庫未公告（例如法務部調查局、矯正署、行政執行署、檢察署），或員額直接寫在組織條例（中央警察大學、警專、工程會）。
