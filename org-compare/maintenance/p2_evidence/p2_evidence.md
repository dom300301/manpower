## 3. 「得列人數」說明與計算是否一致

現行三種計算：
- `得列簡任`（列層級）：備註 `(?:內|其中)N人得列簡任`，僅官等非簡任之列，並以該列員額為上限（cap）。
- `得列薦任`（列層級）：備註 `(?:內|其中)N人得列薦任`，僅官等為「委任」之列，cap 同上。
- `得列人數`（機關層級）：全機關備註串接後以 `內N人得列` 取 N 加總；不含「其中」寫法、不設 cap、不分官等。說明文字「備註『內 N 人得列…』的 N 加總」。
