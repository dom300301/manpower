# 編制表查詢分頁（職稱／官職等／資格軌別）診斷與實作計畫

狀態：**診斷與計畫，尚未改碼**。依既定流程，請先書面同意（可逐項勾選），再於分支實作、跑測試、兩階段提交、開 PR 驗收。
基準：現行部署版 dd3e96b（585 機關、明細 13,380 列、計入 13,293 列）。

## 一、需求理解

新開一個分頁「編制表查詢」，以**明細列（職稱）為單位**而非機關為單位，提供三種查法：

| 查法 | 問題型態 | 範例 |
|---|---|---|
| A 職稱查詢 | 哪些機關有這個（或相似的）職稱？各列什麼官職等？ | 「總幹事」「所長」「督導」在哪些機關、幾人 |
| B 官職等比較 | 同層級、同職稱，單列職等與跨列職等的分布與差異 | 三級機關人事室主任：第九職等／第九至第十職等／簡任第十或薦任第九 |
| C 資格條件（軌別） | 該職務任用是單軌、雙軌或多軌？哪些機關併用？ | 單軌簡薦委；雙軌文職或聘任、文職或醫事；多軌海巡文警軍併用 |

## 二、現有資料診斷（PoC 已跑，數字可重現）

### 2.1 可直接使用的欄位（positions.json 每列已有）
機關、序、單位（僅一條鞭／輔助單位有值）、職稱、官等、職等、職等下限／上限、員額、括號語意、備註、計入。

| 警察官 | 362 | 警正、警佐至警正、警正至警監 |

| 文／軍併用 | 176 | 薦任或中校、少校；簡任或少將 |

### 2.3 官等空白列（1,711）的組成
- 醫事人員 215 列（備註或職等含醫事字樣）＋約 900 列醫院職稱（護士、營養師、物理治療師…）官等欄空白、職等欄或備註才有「師（三）級」等字樣 → 軌別需**同時看職等欄與職稱**。
- 聘任（教育人員、研究員、教授）約 160 列。
- 特任／比照（政務）約 60 列。
- 「由○○兼任」之單位主管列（主任 133、股長、課長）約 200 列：員額 0，屬兼任，不是任用軌別問題。
- 其餘約 250 列（技工、工友、駕駛等不列官等者，或原文無官等）→ 標「無官等（原文）」，不猜。

### 2.4 職等列法
| 列法 | 列數 | 定義 |
|---|---|---|
| 單列 | 2,042 | 職等下限＝上限（第九職等） |
| 跨列 | 8,904 | 下限＜上限（第八至第九職等；第五或第六至第七） |
| 無職等 | 2,347 | 醫事、聘任、特任、兼任列 |

### 2.5 限制（需先說明）
1. **單位欄只有一條鞭／輔助單位有值**（人事室 1,146、主計室 1,202、政風室 721、會計室、統計室…）。中央機關編制表原文不列業務單位，因此「輔助單位比較」可做人事／主計／政風／會計／統計；秘書、資訊等單位無法由編制表辨識。
2. 相似職稱的「相似」只能做文字層次（包含、同義詞表），不做語意推斷；同義詞表（如 組長／科長／課長、所長／場長／館長）列為可編輯清單，預設先給一版請確認。
3. 軌別是**由官等／職等／備註文字規則推導的衍生欄位**，不覆寫原文；規則不確定者標「待審」，不硬分。

## 三、實作計畫

### 3.1 資料層（build_dataset.py，新增衍生欄位，不改既有欄位）
每列新增：
- `職等列法`：單列／跨列／無職等。
- `軌別`：單軌（文）、單軌（警）、單軌（軍）、單軌（醫事）、單軌（聘任）、政務、雙軌（文／醫事）、雙軌（文／軍）、雙軌（文／警）、雙軌（文／關務）、多軌（文／警／軍）、兼任（由他職兼任）、無官等（原文）、待審。
- `軌別依據`：命中的原文片段（如「薦任或警正或中校」「師（三）級」「由護理師兼任」），供點開核對。
- `單位類別`：人事／主計（含會計、統計）／政風／其他一條鞭／（空）。

規則草案（請確認，可增刪）：
| 判定 | 依據 |
|---|---|
| 文 | 官等含 簡任／薦任／委任 |
| 警 | 官等含 警佐／警正／警監 |
| 軍 | 官等含 將／校／尉／士官 |
| 關務 | 官等或職等含「關務」 |
| 醫事 | 官等或職等含 師級／師（N）級／士（生）級，或備註含「醫事人員」，或職稱為醫事職稱清單（醫師、護理師、藥師、物理治療師…） |
| 聘任 | 備註含 聘任／教育人員／教授／研究員，且無上列任何一項 |
| 政務 | 官等或備註含 特任；備註以「比照簡任第 N 職等」起首 |
| 兼任 | 員額 0 且備註含「由…兼任」 |
| 組合 | 命中 2 類＝雙軌、3 類以上＝多軌；備註「或列簡任」「必要時得比照…資格聘任」另加註記「備註另有擇一條款」，不改軌別主分類 |

### 3.2 前端（org_template.html 新分頁「編制表查詢」，資料已內嵌，不增加下載量級）
三個子查詢同頁切換：
- **A 職稱查詢**：輸入職稱（含同義詞勾選）＋篩選 層級／部會／機關類型 → 結果依職稱分組，列出 機關、單位、官等、職等、員額、軌別；上方顯示「N 機關、M 列、員額合計」。
- **B 官職等比較**：選 層級 ＋ 職稱（或 單位類別＋職稱，如 人事室主任）→ 以「官等＋職等」組合為列的分布表（組合、列法、機關數、員額），點組合展開機關清單；可勾選兩個組合並列。
- **C 資格軌別**：選 軌別（多選）＋層級／部會 → 機關清單與各機關該軌別列數、員額；每列可展開看依據原文。
- 共同：結果可下載 CSV（沿用現有匯出），表格沿用現有樣式；手機寬度可用。

### 3.3 測試
- test_p0_dataset.py 新增：軌別總數對帳（各類列數與 2.2 表一致，允許規則調整後更新基準）、海巡 9 機關多軌、醫院列醫事、政務 62 列與政務統計檔一致、兼任列員額 0、無「待審」以外之空值。
- test_p0_frontend.js 新增：分頁可切換；A 查「總幹事」有結果且機關數正確；B 選三級＋人事室主任分布表列數正確；C 選多軌得到海巡 9 機關；CSV 匯出列數一致。
- 既有 84＋27＋9＋17＋38 測試全部維持通過；manifest／dry-run 不受影響（不改來源）。

### 3.4 不在範圍
不重爬、不重 OCR、不改任何人工核定數值、不改機關層比對邏輯、不改 manifest。只新增衍生欄位與一個分頁。

## 四、請確認事項（未回覆者依建議值進行）
1. 軌別分類名稱與規則（3.1 表）是否同意？建議：同意，待審者由貴處後續補規則。
2. 同義職稱表是否要？建議：先內建小表（組長／科長／課長、所長／場長／館長／園長、主任／室主任），可在頁面勾選是否套用。
3. B 比較是否需納入「員額加權」（以人數計）或只計機關數？建議：兩者並列。
4. 分頁名稱：建議「編制表查詢」；既有三分頁不動。
