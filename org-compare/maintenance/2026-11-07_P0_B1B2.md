## B1 範圍篩選 null 安全
- 前：`groupOf()` 以 `a.指標.員額合計>=C.nmin && <=C.nmax` 過濾；JavaScript 中 `null>=0`、`null<=100` 皆為 true，故取消「不可比較」排除後設定上下限時，員額 null 的機關（財政部等）誤入比較清單。
- 後：`nmin` 或 `nmax` 任一有值時，只有 `typeof 員額合計==='number'` 的機關進入範圍判斷；無上下限時 null 機關可留在列表（顯示未取得），中位數／平均的 n 不含它們（原有邏輯）。
- 回歸（前端測試 B1-1～B1-4，農業部為目標、取消排除）：上限 100 下限空 → 財政部不在清單；範圍 0–100 → 不在清單；財政部為目標按 ±50% → 仍阻擋、未形成 [0,0]；無上下限 → 財政部在列、統計列 n 等於數值列數（不含目標與 null）。

## B2 法定員額依據 UI
- 前：`有===false` 時顯示粗體「無」，連結字樣「，條文）」。
- 後：主文案「尚未完成結構化（待確認）」，括號內續顯示既有說明（「本系統尚未完成員額結構化…」或「依共用法規…」）與法規名稱連結；`有===true` 維持法規名稱、條號、連結與「本系統未加總」。「有」欄語義未變，不表示已證實法規無員額。
