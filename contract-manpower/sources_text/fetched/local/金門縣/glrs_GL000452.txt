 法規沿革 
 一、約用人員擬支給證照加給者，應訂定職務說明書，職務說明書應包含以下內容： 
 ( 一 ) 所在單位：係本職務所隸屬之單位。 
 ( 二 ) 工作項目：填寫實際執行之工作項目，並以不超過 3 項為原則，每項工作應註明百分比。 
 ( 三 ) 所需知能：指各工作項目所需之學識、才能、技術、訓練等。 
 二、證照加給 須領有下列證照之一，且該領有之證照與百分比達 70% 以上之工作項目具高度相關性者， 始得支給： 
 ( 一 ) 領有專門職業及技術人員普通考試或專門職業及技術人員特種考試 ( 相當普通考試 ) 及格證書者。 
 ( 二 ) 領有勞動部甲級、乙級及單一級技術士技能檢定證書者。 
 ( 三 ) 領有經濟部自來水事業技術人員甲級 、 乙級合格證書者。 
 三、約用人員領有之證照符合第二點規定者，得支給加給新台幣 1,200 元整；領有兩張以上證照，且該兩證照均與百分比達 70% 以上之工作項目具有高度相關性者，得支給 1,600 元。 
 四、領有之證照如係該職務原徵才公告所列須具備之資格條件者，不得支給證照加給。 
 五、證照如係由本府補助費用取得者，依第三點加給金額折半支給。 
 六、工作項目如經調整，即應予停發，請各機關學校加強列管。 
 七、各機關學校應檢具約用人員支給證照加給審核表及證照影本報府備查。 
 八、所需增加之經費由各機關學校業務費項下勻支 。
