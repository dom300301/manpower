# 契約人力制度查詢系統　操作手冊

## 一、這套系統是什麼

把聘用、約僱、約用（臨時）、勞務承攬等契約人力的**法規全文、法制沿革與草案、各類人員權益對照、歷年員額統計、22 縣市制度樣態**整理成結構化資料，再編成一個離線網頁 `output/index.html`。雙擊即可查詢，不需安裝、不需伺服器；也可放雲端硬碟或上 GitHub Pages。

| 位置 | 內容 |
|---|---|
| `output/index.html` | **查詢網頁**（單檔，約 5 MB） |
| `data/` | 結構化資料（見第三節），是系統的唯一資料來源 |
| `research/01～06` | 研究報告（法規清冊、統計來源、沿革與草案、地方樣態、權益對照、人力消長） |
| `00_研究架構與待決事項.md` | 研究設計與待您確認的事項 |
| `build.py`、`template.html` | 建檔程式與網頁樣板 |
| `scripts/` | 各資料集的產生與驗證程式 |
| `raw/` | 下載的原始檔（不進版控，重跑 scripts 可再取得） |

## 二、查詢網頁五個分頁

1. **法規**：35 部法規全文。輸入關鍵字（空白分隔多個）可同時搜法規名稱與條文，符合的條文會列在卡片上並標黃；可依人員類別／主題標籤、位階篩選；展開「全文、沿革、來源」看整部法規與歷次修正。
2. **沿革**：57 筆事件的時間軸（1969 年至今），可依行動者（考試院、行政院、立法院、監察院…）與類型篩選，每筆附「制度論觀點」註記與來源連結；右側列 9 份歷次專法草案，展開可看條文要點、爭議與現制差異。
3. **權益對照**：五類人員 × 20 項權益的矩陣，每格下方灰字是法源條號，打勾者表示已用法規全文核對。上方可勾選只看「進用」「待遇」「保險」「退休」「義務」「救濟」等群組。
4. **員額趨勢**：先選範圍（中央／地方／全國）、機關（行政院所屬、各部會、各縣市…）、量度（實有人數／預算員額），再點選要畫的類別（最多 8 條線）。滑鼠移到圖上會顯示該年各線數值；展開「資料表」可看每筆數字的來源連結。按「**目的二對照**」會一鍵疊合聘用、約僱、事務性人力、第二類近似值與約用人員。
5. **地方樣態**：22 縣市總表（規定條目可展開「條文全文」）（契約人力類型、隨首長進退、適用勞基法、總量管制、公權力限制），下方卡片列各縣市規定與來源；可用右上篩選器只看「有總量管制」等。

6. **報告文獻**：立法院法制局與預算中心報告、監察院調查報告與糾正案、審計部年報摘錄、博碩士論文書目，可依來源篩選、全文關鍵字搜尋，展開看重點發現、建議與關鍵數字。

## 三、資料檔與維護方式

| 檔案 | 內容 | 來源與更新程式 |
|---|---|---|
| `data/laws.json` | 35 部法規全文、沿革、標籤 | 全國法規資料庫 API、人事總處、考試院法規系統；`python3 -I scripts/build_laws.py` 重抓，`scripts/verify_laws.py` 驗證 |
| `data/headcount.csv` | 9,931 列歷年各類人員人數 | 人事總處公教人力統計年報、銓敘部概況統計；`scripts/build_headcount.py`、`verify_headcount.py` |
| `data/headcount_sources.json` | 112 個統計來源檔的網址與解析方式 | 同上 |
| `data/timeline.json`、`data/drafts.json` | 沿革事件、草案 | 人工整理（依 WebSearch 與可取得文件），直接編輯 JSON |
| `data/comparison.json` | 權益對照矩陣 | 人工整理並以 laws.json 核對；直接編輯 JSON，`verified` 設 true 會顯示打勾 |
| `data/local_gov.json` | 22 縣市樣態與 96 件規定全文 | `scripts/build_local_gov.py`、`scripts/local_fulltext/`（抓取與整併）、`verify_local_gov.py` |
| `data/reports.json`、`reports_oversight.json`、`literature.json` | 法制局／預算中心報告、監察院／審計部文件、論文書目 | 人工整理（原始 PDF 在 `raw/fetched/`）；`verify_reports.py`、`verify_oversight.py` |
| `data/dgbas_總員額法摘要.json` | 總員額法五類員額逐年摘要 | `scripts/build_dgbas_headcount.py` |

**更新流程（任何資料改動後）**

```bash
cd contract-manpower
python3 build.py
```

畫面會列出每個資料檔讀到幾筆，缺少的檔會以空資料代替並在網頁上提示。產出後打開 `output/index.html` 檢查即可。

**每年例行更新（建議每年 3–4 月，人事總處年報公布後）**
1. `python3 -I scripts/build_headcount.py` 重新下載並解析統計（需可連 dgpa.gov.tw、mocs.gov.tw）。
2. `python3 -I scripts/verify_headcount.py` 檢查。
3. `python3 -I scripts/build_laws.py` 重抓法規（會自動帶入新修正）。
4. `python3 build.py` 建檔。

## 四、線上版（GitHub Pages）

與組織法規查詢系統放在同一個網站：

| 網址 | 內容 |

| `https://dom300301.github.io/manpower/` | 組織法規與編制表查詢系統 |
| `https://dom300301.github.io/manpower/contract/` | 契約人力制度查詢系統 |

發佈流程由 `.github/workflows/pages.yml` 自動執行：只要預設分支（`claude/dreamy-davinci-0xuicp`）上任一個 `output/index.html` 有更新，就會重新發布兩套系統，約 1～2 分鐘生效。也可到 GitHub「Actions」頁籤選「發布查詢網頁」，按「Run workflow」手動發布。

**更新線上版的步驟**
1. 資料更新後執行 `python3 build.py`，產生新的 `output/index.html`。
2. commit 並合併到預設分支（由 Claude 開合併請求，您在 GitHub 按「Merge」）。
3. 合併後自動發布。

本系統資料全為公開資料，無機敏內容；網頁設有 `noindex`，不會被搜尋引擎收錄，但任何人取得網址即可開啟。

## 五、已知限制

- 大部分原文已於 115.10.31 補抓。仍缺：考試院主站文件（見第七節）、法制局 B00493／A00500 全文（網站只公開摘要）、89 與 91 年基準法草案、審計部總決算審核報告全文、苗栗與連江地方規定、桃園／高雄／基隆最新版要點、博碩士論文全文。各分頁中標示「全文未取得」者即屬此類。
- 勞務承攬人力沒有全國統計，僅監察院與審計部報告中的零星數字。
- 員額趨勢分頁有兩種第二類員額：「目的二對照（法定分類）」為主計總處預算員額（正式口徑）；「目的二對照（實有）」中的「近似值」為實有人數合成，用來與約用人員同圖比較。

## 七、考試院資料的更新方式

**目前狀況**：考試院主站 `www.exam.gov.tw` 與開放資料站 `ws.exam.gov.tw` 的網域已開放，但該網站伺服器的憑證鏈不完整（缺中繼憑證），雲端環境的網路閘道會拒絕連線（回 502）。這不是網域清單的問題，雲端端無法自行修正；考試院法規系統 `law.exam.gov.tw` 則正常。

**方式 A：由您下載檔案交給 Claude（建議）**
1. 在辦公室電腦用瀏覽器開考試院網站，下載需要的 PDF 或 Word（見下方清單）。
2. 把檔案上傳到雲端硬碟「契約人力制度研究／考試院資料」資料夾，或直接拖進 Claude 對話。
3. 告訴 Claude：「請把雲端硬碟某某資料夾的考試院資料整合進契約人力系統」。
4. Claude 會解析內容、寫入 `data/drafts.json`（草案）、`data/timeline.json`（事件）或 `data/reports.json`（研究報告），執行 `python3 build.py` 與各驗證程式，更新研究報告第 03 號，然後 commit。

**方式 B：日後網站恢復正常時**
直接告訴 Claude「重抓考試院資料」，Claude 先測試連線，可連時依下方清單自動下載與整合。

**待補的考試院資料清單**
- [ ] 106 年考試院審議之「契約人員人事條例草案」考試院版條文與總說明（未送立法院，只在考試院）
- [ ] 考試院院會新聞稿：94 年聘用人員人事條例草案通過、約聘人員人事條例「暫緩研訂」決議（確認年份）
- [ ] 銓敘部 111 年宣示研修「聘用人員聘用條例」後的草案與是否送審
- [ ] 文官制度興革規劃方案（契約人力相關章節）、考試院委託研究（柯三吉 2008 等）
- [ ] 全國公務人員人數開放資料（data.gov.tw 166465，下載網址在 ws.exam.gov.tw）

**自行小幅修改（不經 Claude）**：用文字編輯器開 `data/timeline.json`，複製一筆既有事件、改內容後存檔，再執行 `python3 build.py`。若畫面出現 JSON 錯誤，通常是少了逗號或引號，可把錯誤訊息貼給 Claude 處理。
