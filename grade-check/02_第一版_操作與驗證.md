# 官職等配置審核系統　第一版　操作說明與驗證紀錄

建置日期：2026-11-01　　狀態：第一版（規則引擎＋查詢網頁＋模擬修編）

---

## 一、怎麼用

### 查詢網頁 `grade-check/output/index.html`
雙擊即可用（Edge／Chrome）。四個分頁：

| 分頁 | 功能 |
|---|---|
| 機關檢核 | 搜尋機關 → 逐條檢核結果（規則、條文、計算式、數值、門檻、結果、差距、說明）、編制表明細與第 6 條拆算、每列職稱列等對照狀態；可「複製檢核結果」貼到 Word／Excel；不符者自動列出「建議請機關補充說明」的題目 |
| 模擬修編 | 由機關檢核「帶入模擬」，直接改職稱、官等、職等、員額、備註，按「重算」比較修編前後：比率、各規則結果、改善／惡化、距門檻點數、調整方向與補充說明清單。計算在瀏覽器內完成，資料不外傳 |
| 職稱列等查詢 | 選層級、輸入職稱 → 各列等組合的機關數、員額、暫列機關數、機關清單 |
| 規則與說明 | 規則清單、機關類別初判表下載、限制 |

線上版：合併到預設分支後，GitHub Pages 會發布在 `/grade/`（與組織法規查詢系統同一網站）。

### 更新資料（三個指令）
```bash
python3 grade-check/build_grade_table.py      # 總表 → 職稱列等對照表（rules/title_grades.json）
```
```bash
python3 grade-check/check_grades.py           # 總表 → 逐機關檢核（output/check_results.json、檢核結果_全機關.csv）
```
```bash
python3 grade-check/build_grade_site.py       # 檢核結果 → output/index.html
```
總表更新時（組織法規查詢系統的更新流程）重跑這三步即可。

### 要請同仁填的表
`grade-check/rules/agency_category.csv`：程式已初判每個機關的附表三類別，請在「人工確認類別」欄填入確認結果（類別名稱見 `rules/ratio_table.json`），並視需要填「雙軌制」「駐外」「例外核備紀錄」。填好後重跑 `check_grades.py`，結果會改用人工確認的類別並標示「已確認」。

## 二、第一版實作的規則

| 規則 | 依據 | 判定 | 本版假設（待與銓敘部試算表核對） |
|---|---|---|---|
| R1 簡任比率 | 第 5 條、附表三 | 簡任÷薦任 ≤ 上限 | 類別由程式初判 |
| R2 委任比率 | 第 5 條、附表三 | 委任÷各官等總數 ≥ 下限 | 同上 |
| R3 拆算 | 第 6 條 | 委任至薦任→薦任；委任或薦任→1/3、2/3，尾數歸高；得列依備註移轉 | 警察、軍職、師級、特任、比照不計 |
| R3a | 第 4 條第 1 項第 4 款 | 非主管不得高於副首長、幕僚長 | 副首長＝「副」＋首長職稱、次長；幕僚長＝主任秘書、秘書長 |
| R3b | 第 4 條第 1 項第 6 款 | 首長、副首長以外職稱之職等應接續 | 首長、副首長不計 |
| R4 | 第 7 條第 1 項 | 30 人以上應置委一至三職等（未滿 100 人 1 人、以上 2 人） | 115.9.30 已提刪除草案 |
| R5 | 第 7 條第 2 項 | 委四至五職稱員額 ≥ 委五或薦六至七職稱員額之 1/12 | 分子＝列委任第四至五職等之職稱員額 |
| R6 | 第 7 條第 3 項 | 4～11 人機關應置委任職稱 | |
| R7 | 第 8 條 | 薦七以下薦任非主管 ÷ 薦任非主管 ≥ 40%／50%（工程 45%、調查 5%） | 「薦七以下」＝職務列等上限 ≤ 7；主管以職稱判定 |
| R9 | 第 9 條第 2 款 | 三級署局參議 ≤（幕僚長＋一級業務單位主管）÷2 | 派出單位及所屬機關首長加計未納入 |
| R10 | 第 9 條第 5 款 | 中央二、三級簡任非主管 ≤ 科長員額 × 7/10 | 不含參事、技監、顧問、參議、研究委員、研究員、公職律師、消保官 |
| R11 | 第 4 條、職務列等表 | 每列職稱與列等對照同層級實證分布：主流／少數／未見 | 實證分布不是上限 |
| R13 | 111.9.23 附表三 | 舊制比率（母數皆為總數） | 舊比率表由公報文字擷取，待核對 |

未實作：第 9 條第 1 款（二級機關高階參贊職務上限，需所屬三級機關首長數）、第 10 條（兼任官等）、第 11 條（留用）、職務列等表現行各表（公開網站無）。

## 三、驗證結果（571 個有編制表明細的機關）

| 規則 | 符合 | 不符 | 不適用／需確認 | 備註 |
|---|---|---|---|---|
| R1 簡任比率 | 378 | 20 | 173 | 不符者多為二級機關（簡任非主管多）與特殊結構機關（農田水利署等） |
| R2 委任比率 | 444 | 50 | 77 | 不符集中在研究機關（研究職稱多為薦任以上）與四級小機關 |
| R3a | 443 | 1 | | 國防部研究員高於幕僚長 |
| R3b 跳空 | 539 | 19 | | 多為小機關缺第 6 或第 10 職等 |
| R4 委一至三 | 380 | 24 | 167 | 不符者幾乎都是農業部試驗所、改良場（100 人以上只置 1 名書記） |
| R5 委四至五 | 441 | 53 | | 不符者多為工程、關務機關 |
| R7 薦七以下 | 413 | 49 | | 不符者多差 1～9 人 |
| R10 簡任非主管 | 95 | 15 | 47 | 農業部、交通部、金管會銀行局等二級機關超過 7/10；47 個機關查無科長需人工確認 |
| R11 職稱列等 | 571 | | | 無「本層級未見之職稱列等」 |
| R13 舊制 | 341 | 50 | 49 | 舊制不符者多為舊制委任下限較高所致 |

**抽樣核對**：海洋保育署（三級署）委任 23／薦任 70／簡任 10，簡任比率 14.3%、委任比率 22.3%，各規則皆符合，與人工依 PDF 計算一致；農業部簡任比率 39.8%（上限 40%）符合，但第 9 條第 5 款簡任非主管 60 人超過科長 45×0.7，屬修正前即存在之結構，依總說明應於修編時維持或降低比例。

**模擬修編測試**：海洋保育署專門委員 3→20 人，簡任比率 14.3%→38.6%（惡化，超上限 3.6 點），系統正確標示 R1 不符、需減簡任 3 人或增薦任 8 人，並列出可調整職稱與補充說明清單。

## 四、已知限制（第一版）

1. 機關類別為程式初判，影響 R1、R2 門檻；請同仁確認 `rules/agency_category.csv`。
2. 主管／非主管、二級單位主管數以職稱推定；處務規程單位資料尚未接入。
3. 雙軌制機關（警察、海巡、醫療、國防）只計單列官等職等員額，比率僅供參考。
4. 例外核備紀錄（第 13 條）未納入。
5. 職務列等表現行各表無公開版本，R11 以實證分布替代；待貴處提供 114 年通函調整範圍後加「可列上限」層。
