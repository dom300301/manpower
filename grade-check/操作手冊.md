# 官職等配置審核系統　操作手冊與交接說明

版本：第一版（2026-11-01）　　適用對象：組編人力處同仁（不需程式背景）

---

## 一、這套系統是什麼

- 一個網頁檔 `index.html`，內含行政院所屬 571 個機關（有編制表明細者）依「各機關職稱及官等職等員額配置準則」（114 年 12 月 4 日修正）逐條檢核的結果，以及 585 個機關編制表彙整出的「職稱列等對照表（實證版）」。
- 三個用途：
  1. **審查**：查某機關現行編制表哪一條不符、差幾人、該請機關補充說明什麼。
  2. **模擬修編**：把擬修的編制表填進去重算，看修編前後是改善還是惡化、距門檻幾點。
  3. **查職稱列等**：某層級某職稱在各機關實際核備的官等職等分布（含暫列）。
- 不連網也能用；合併到 GitHub 預設分支後，線上版在 GitHub Pages 的 `/grade/` 路徑（與組織法規查詢系統同一網站）。
- 本系統是輔助審查工具，正式認定仍依銓敘部與考試院。

## 三、怎麼用查詢網頁

1. 雙擊 `index.html`（Edge 或 Chrome；約 1 秒載入）。
2. **機關檢核**：左側輸入機關名稱（空格分隔＝同時符合），可篩層級、只看有不符。點機關後右側顯示：
   - 基本資料、編制表 PDF 連結、機關類別（註「程式初判」者尚未經人工確認）。
   - 指標卡：定有官等職等員額、委／薦／簡任員額、簡任比率與上限、委任比率與下限。
   - 逐條檢核表：規則、條文、項目、計算式、數值、門檻、結果（綠符合／紅不符／黃需確認／灰不適用）、差距、說明。
   - 有不符時自動列出「建議請機關補充說明」。
   - 編制表明細：每列的委／薦／簡拆算、是否主管、列等對照狀態（主流／少數／實證未見）。
   - 「複製檢核結果」→ 貼到 Word 或 Excel；「帶入模擬」→ 到模擬修編分頁。
3. **模擬修編**：直接改表格（職稱、官等、職等、員額、備註），可新增或刪除列，按「重算」。官等請用準則用語（委任、薦任、簡任、委任或薦任、薦任至簡任…），職等用「第八職等至第九職等」寫法，得列寫在備註「內二人得列簡任第十職等」。結果顯示修編前後比率、各規則結果、改善／惡化、距門檻點數、調整方向與補充說明清單。
4. **職稱列等查詢**：選層級、輸入職稱（有下拉提示），顯示各列等組合的機關數、員額、暫列機關數，展開可看機關清單。
5. **規則與說明**：規則清單、機關類別表下載、限制。

## 四、更新作業

### 情境 A：總表更新（組織法或編制表修正、新機關）
先依組織法規查詢系統的流程更新總表（`org-compare/操作手冊.md`），再執行本系統三步建檔。

**做法一：請 Claude 做**。在 Claude Code 開啟 `dom300301/manpower`，輸入：
> 請執行官職等配置審核系統更新：重建職稱列等對照表、重跑檢核、重建網頁，並推送到分支。

**做法二：自己在 Mac 上雙擊**。前置（一次）：安裝 Python 3，下載 `grade-check` 資料夾與 `org-compare/data/` 總表，雙擊 `0_首次安裝.command`。之後雙擊 `1_建檔.command`，會依序執行：
```bash
python3 build_grade_table.py     # 總表 → 職稱列等對照表
python3 check_grades.py          # 總表 → 逐機關檢核
python3 build_grade_site.py      # 檢核結果 → output/index.html
```
完成後把 `output/index.html` 與 `檢核結果_全機關.csv` 上傳雲端硬碟或推回 GitHub（推回預設分支會自動重新發布線上版）。

### 情境 B：機關類別確認或例外紀錄補登
在 `rules/agency_category.csv` 填「人工確認類別」「雙軌制」「駐外」「例外核備紀錄」，存檔後重跑 `check_grades.py` 與 `build_grade_site.py`。類別名稱請用 `rules/ratio_table.json` 內的名稱。

### 情境 C：準則或附表三修正
改 `rules/ratio_table.json`（比率）或 `check_grades.py`（條文邏輯，請 Claude 改），重跑後兩步。第 7 條第 1 項刪除草案發布後，R4 規則停用。

### 情境 D：法規更新偵測
```bash
python3 fetch_exam_laws.py       # 考試院主管法規開放資料 → regs/（準則、作業要點等全文）
python3 fetch_exam_council.py    # 考試院公報開放資料與院會紀錄 → 關鍵字索引（職務列等調整多以院會決議辦理）
```
需開放 law.exam.gov.tw、www.exam.gov.tw、gazette.exam.gov.tw、ws.exam.gov.tw。

## 六、常見問題

- **網頁打開是空白**：請用 Edge 或 Chrome 新版；舊版瀏覽器不支援資料解壓。
- **某機關找不到**：總表沒有該機關編制表明細（14 個機關無編制表或待人工輸入）。
- **結果和銓敘部試算不一樣**：先看「規則與說明」的三項假設；再看該機關是否雙軌制或類別未確認。
- **想加規則或改門檻**：比率在 `rules/ratio_table.json`；條文邏輯在 `check_grades.py`，請 Claude 協助修改並重跑驗證。
