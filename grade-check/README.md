# 官職等配置審核系統（第一版）

依「各機關職稱及官等職等員額配置準則」（114.12.4 修正）檢核行政院所屬機關編制表的官等員額配置，並提供修編調整建議。資料來源與 `org-compare/` 共用同一份總表。

| 檔案 | 用途 |
|---|---|
| `00_需求檢視與架構規劃.md` | **請先讀**：規範收集結果、資料缺口、PoC 結果、三層面需求檢視、建議架構、待決事項 |
| `02_第一版_操作與驗證.md` | **操作說明**：網頁四個分頁、三個更新指令、規則假設、驗證結果、限制 |
| `check_grades.py` → `output/check_results.json`、`output/檢核結果_全機關.csv` | 規則引擎（逐機關、逐條檢核） |
| `build_grade_site.py` + `grade_template.html` → `output/index.html` | 查詢網頁（離線單檔；GitHub Pages `/grade/`） |
| `rules/ratio_table.json`、`rules/agency_category.csv`、`rules/title_grades.json` | 附表三比率（新舊制）、機關類別初判表（請填人工確認）、職稱列等對照表 |
| `01_職稱列等對照表_建置報告.md` | 以 585 機關編制表實證分布建立的職稱列等對照表：做法、結果、驗證、限制 |
| `build_grade_table.py` → `data/職稱列等對照表_實證_日期.xlsx`、`rules/title_grades.json` | 職稱列等對照表建置程式與產出 |
| `regs/` | 配置準則全文、附表一至三、修正總說明（含修正前比率表）、作業要點、地方機關作業原則、師級醫事配置準則、職務列等表說明與目錄；純文字版與原始 PDF |
| `fetch_exam_laws.py` | 從考試院主管法規開放資料下載上述法規全文（可重跑，供更新偵測） |
| `fetch_exam_council.py` | 下載考試院公報開放資料與院會紀錄，產生「列等／配置準則」關鍵字索引（職務列等調整實際上以院會決議辦理，需由此追蹤） |
| `regs/職務列等表/` | 職務列等表取得狀況、實際運作機制說明、113 年甲表草案全表、114 年通案調整新聞稿、院會紀錄索引與關鍵紀錄 |
| `poc/ratio_poc.py` | 概念驗證：依第 5、6 條計算全部機關的簡任、委任比率並粗略對照附表三 |
| `poc/官等比率_PoC.csv` | PoC 結果（558 機關） |

補充（2026-10-31 第二次收集）：`regs/職務列等表/` 說明職務列等表的取得狀況與建議；`regs/配置準則第7條修正草案_115.09.30函陳考試院.md` 為尚未發布的修正草案。
